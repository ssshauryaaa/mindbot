# Pyrobot Demo Checklist (SYNAPTICA Event)

## 15 Minutes Before Demo

- Laptop charged and charger connected
- Internet hotspot ready
- Browser tab with app loaded (`http://localhost:5173`)
- `.env` keys verified
- `npm run dev` running without errors

## Live Readiness Checks

- Send one normal prompt and confirm AI response
- Toggle mode (`Logic`/`Empathy`) and verify behavior shift
- Toggle `Safe Demo Mode` ON
- Temporarily disable internet and verify local fallback response appears
- Re-enable internet and verify normal AI response resumes

## 3-Minute Demo Script

1. **0:00–0:30** — Introduce SYNAPTICA: logic + empathy in one assistant  
2. **0:30–1:40** — Ask one question in two modes to show duality difference  
3. **1:40–2:20** — Show student-focused real-world help (career or stress plan)  
4. **2:20–2:45** — Show fallback continuity when connectivity fails  
5. **2:45–3:00** — Summarize AI tools, architecture, and originality

## Judge Q&A Quick Answers

- **Originality:** duality engine + sentiment adaptation + resilient multi-provider routing
- **Accuracy:** structured JSON outputs, schema checks, one-pass quality retry
- **Reliability:** timeout/retry network control + local fallback continuity
- **Usefulness:** helps students make practical, emotionally balanced decisions

## Backup Plan

- Keep 3 fixed demo prompts copied in notes
- If one provider fails, switch to OpenRouter
- If internet fails, keep Safe Demo Mode ON and continue with fallback
